# Increment 1: ship and friction

## The pattern

A convergent shipping command. `foundry ship` reads the current state at every step (branch pushed? PR open? body current? CI green? friction answered?) and does only what is missing, so a rerun after any stop resumes, and a rerun on a finished branch writes nothing. The agent's loop is just "read the last line, do what it says, rerun". Friction is a required step, not a courtesy: ship does not reach `ready for human` until the branch has filed a report or said why it had none.

## What surprised me

- Shipping foundry with foundry found more bugs than the whole-branch review. The fakes encoded my belief about vouch, not vouch: the fake printed gate findings on stdout and exited 1, while real vouch prints them on stderr and exits 2. Three stops were wrong in real use: findings were shown as a transient failure, a vouch run error as findings, and an exit 1 as findings.
- The review gate converged. Each round raised fewer findings, and the last three were all deferrable minors that I filed as friction (#6, #7).
- Environment state leaked into the product path. A stale gitnexus registry entry from an old tool blocked vouch's indexing of atlas. A `go install` into a GOBIN behind `~/.local/bin` on PATH meant two ship runs used a stale binary (#5).
- Stacked PRs broke the merge order. The plan PR targeted the spec branch, so once the spec merged first, the plan never reached main and needed a second PR (#3).

## What I would do differently

- Build each fake from the real tool's source, exit codes and streams included, before writing the adapter.
- Open stage PRs against main once the earlier stage has merged, instead of stacking them.
- Print the binary's revision first in every run.

## What I still do not understand

- How noisy the friction loop gets once several agents ship a week. The dedupe is by title, and I do not know yet whether that is enough.
- Whether "every check must pass" is right. The spec says required checks only. Ship requires all of them and prints name, bucket and link instead of a log tail, so a failing optional check blocks hand-off. Decide after real use.
- `gh label create --force` resets maintainer label styling on every filing. Deferred, as the friction cap was spent.
